# Bubble 3D Reconstruction: Algorithm Plan

## Overview

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        BUBBLE 3D RECONSTRUCTION                              │
│                                                                              │
│  Input:  4 calibrated camera views × N frames (2D silhouettes)              │
│  Output: Per-bubble, per-frame spherical harmonic coefficients + centroid   │
│                                                                              │
│  Key Innovation: Multi-constraint optimization combining                     │
│                  - Visual hull as upper bound                                │
│                  - Physical priors (surface tension, volume conservation)   │
│                  - Temporal consistency                                      │
│                  - Robust handling of overlaps and mask imperfections        │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Stage 1: Per-Frame 3D Reconstruction

### Step 1.1: Visual Hull Computation

```
Input:  4 binary silhouettes + camera projection matrices
Output: 3D voxel grid (all bubbles combined)
Method: Space carving

┌─────────────────────────────────────────────────────────┐
│  For each voxel in 3D grid:                             │
│    Project voxel center to all 4 cameras                │
│    If inside silhouette in ALL views → keep voxel       │
│    Otherwise → discard                                  │
│                                                         │
│  Also compute: Signed Distance Field (SDF) of VH        │
│    - SDF < 0: inside VH                                 │
│    - SDF > 0: outside VH                                │
│    - Used later for constraint enforcement              │
└─────────────────────────────────────────────────────────┘
```

**Key Point:** Visual hull represents the **maximal possible shape** — true bubble surface must be inside or on VH boundary.

---

### Step 1.2: 3D Bubble Separation

```
Input:  Visual hull voxel grid
Output: List of individual bubbles with voxels, centroid, volume

Method: 3D connected component labeling

┌─────────────────────────────────────────────────────────┐
│  Critical Insight:                                      │
│                                                         │
│  Even if bubbles OVERLAP in 2D views,                   │
│  they SEPARATE in 3D space!                             │
│                                                         │
│  Camera 1 view:  ◯◯  (overlapping)                      │
│  Camera 2 view:  ◯◯  (overlapping)                      │
│  3D reality:     ◯  ◯  (separated)                      │
│                                                         │
│  → Use regionprops3D to get each bubble's:              │
│    - Voxel set                                          │
│    - Centroid                                           │
│    - Volume (voxel count)                               │
│    - Bounding box                                       │
└─────────────────────────────────────────────────────────┘
```

---

### Step 1.3: Back-Projection to 2D (Per Bubble)

```
Input:  Single bubble's 3D voxels + camera matrices
Output: Per-camera projected mask of this bubble

Purpose: Determine which 2D pixels belong to this specific bubble

┌─────────────────────────────────────────────────────────┐
│  For each camera:                                       │
│    Project this bubble's voxels → 2D mask               │
│    Project other bubbles' voxels → 2D mask              │
│                                                         │
│  This tells us:                                         │
│    - Where this bubble SHOULD appear in 2D              │
│    - Where it's OCCLUDED by other bubbles               │
│    - Where mask might be ERRONEOUS                      │
└─────────────────────────────────────────────────────────┘
```

---

### Step 1.4: Overlap & Quality Analysis (Per Bubble, Per Camera)

```
Input:  Projected bubble mask, other bubbles mask, observed silhouette
Output: Overlap ratio, mask quality score, boundary classification

┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  OVERLAP DETECTION:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  overlap_region = projected_this_bubble ∩ projected_others  │   │
│  │  overlap_ratio = |overlap_region| / |projected_this_bubble| │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  MASK QUALITY ASSESSMENT:                                           │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  expected_region = projected_this_bubble (from VH)          │   │
│  │  observed_region = observed_silhouette ∩ expected_region    │   │
│  │                                                              │   │
│  │  missing = expected - observed  (mask has holes)            │   │
│  │  extra = observed - expected    (mask has noise)            │   │
│  │                                                              │   │
│  │  quality_score = f(IoU, missing_ratio, extra_ratio,         │   │
│  │                    boundary_smoothness)                      │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  BOUNDARY POINT CLASSIFICATION:                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  For each point on projected VH boundary:                   │   │
│  │                                                              │   │
│  │    "reliable"   - Not overlapped, observed ≈ projected      │   │
│  │    "overlapped" - Behind another bubble                     │   │
│  │    "mask_error" - Observed ≠ projected, not overlap         │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

---

### Step 1.5: Constraint Selection & View Weighting

Based on overlap and quality analysis, determine how to use each camera's information:

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  VIEW WEIGHT ASSIGNMENT:                                            │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  If overlap_ratio > 0.5:                                    │   │
│  │      weight = 0.2  (heavily occluded, low trust)            │   │
│  │                                                              │   │
│  │  Else if overlap_ratio > 0.1:                               │   │
│  │      weight = 0.5 × quality_score                           │   │
│  │                                                              │   │
│  │  Else:                                                       │   │
│  │      weight = quality_score  (clean view, full trust)       │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  CONSTRAINT TYPE SELECTION:                                         │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  "reliable" boundary points:                                 │   │
│  │      → EXACT constraint (surface should project here)       │   │
│  │      → Use OBSERVED boundary position                        │   │
│  │      → Full confidence                                       │   │
│  │                                                              │   │
│  │  "overlapped" boundary points:                               │   │
│  │      → UPPER BOUND constraint only                          │   │
│  │      → Surface must not exceed this point                   │   │
│  │      → Cannot see true boundary, only limit                 │   │
│  │                                                              │   │
│  │  "mask_error" boundary points:                               │   │
│  │      → APPROXIMATE constraint                               │   │
│  │      → Use PROJECTED VH position (more reliable than mask)  │   │
│  │      → Low confidence                                       │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

---

### Step 1.6: Progressive Constrained SH Fitting

```
Input:  Constraints, VH SDF, expected volume, previous frame SH
Output: Optimal SH coefficients for this bubble

┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  PROGRESSIVE DEGREE FITTING:                                        │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  Purpose: Avoid "flower pattern" artifacts                  │   │
│  │           Start simple, add detail only if needed           │   │
│  │                                                              │   │
│  │  for degree in [0, 1, 2, 3, 4, 5]:                          │   │
│  │      if degree == 0:                                        │   │
│  │          initialize with sphere matching expected volume    │   │
│  │      else:                                                  │   │
│  │          initialize with previous degree solution           │   │
│  │          (new coefficients = 0)                             │   │
│  │                                                              │   │
│  │      optimize with constraints                              │   │
│  │                                                              │   │
│  │      if degree >= 2 and improvement < 1%:                   │   │
│  │          stop (converged)                                   │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  INITIALIZATION PRIORITY:                                           │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  1st choice: Previous frame's SH (temporal continuity)      │   │
│  │  2nd choice: Ellipsoid fit to VH points                     │   │
│  │  3rd choice: Sphere with expected volume                    │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## Constraint System

### Overview Table

| Category | # | Constraint | Type | Purpose |
|----------|---|------------|------|---------|
| **Hard** | H1 | Visual Hull Bound | Inequality | Surface ⊆ VH |
| **Hard** | H2 | Star Convexity | Inequality | r(θ,φ) > 0 everywhere |
| **Data** | D1 | Silhouette Match | Weighted L2 | Fit observations |
| **Data** | D2 | Upper Bound (overlap) | One-sided | Limit in occluded regions |
| **Physical** | P1 | Volume Conservation | Soft equality | Mass conservation |
| **Physical** | P2 | Curvature Uniformity | Regularization | Surface tension → smooth H |
| **Physical** | P3 | Max Curvature | Inequality | No sharp features |
| **Physical** | P4 | Convexity | Soft (We-dependent) | Small bubbles are convex |
| **Physical** | P5 | Aspect Ratio | Inequality | Breakup stability limit |
| **Regularization** | R1 | Spectral Smoothness | L2 penalty | Anti-flower (penalize high l) |
| **Regularization** | R2 | Temporal Smoothness | L2 penalty | Frame-to-frame consistency |

---

### Constraint Details

#### H1: Visual Hull Upper Bound (CRITICAL)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: SH surface must NOT exceed visual hull                    │
│                                                                     │
│  Why: VH is intersection of all viewing cones                       │
│       True surface MUST be inside VH                                │
│       Any point outside VH is physically impossible                 │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  For all surface points p on SH surface:                    │   │
│  │      SDF_vh(p) ≤ 0                                          │   │
│  │                                                              │   │
│  │  Penalty = Σ max(SDF_vh(p), 0)²                             │   │
│  │                                                              │   │
│  │  (Only penalize points OUTSIDE VH)                          │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Implementation:                                                    │
│  - Sample ~2000 points on SH surface                               │
│  - Query VH SDF at each point                                      │
│  - Sum squared positive SDF values                                 │
│                                                                     │
│  Weight: λ_vh = 1000-10000 (hard constraint, very high)            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### H2: Star Convexity (CRITICAL for SH validity)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Ensure valid SH representation                            │
│                                                                     │
│  Why: SH radius representation r(θ,φ) assumes every ray from       │
│       centroid hits surface EXACTLY ONCE                            │
│       If r ≤ 0 anywhere, representation breaks                      │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  r(θ,φ) > r_min > 0  for all (θ,φ)                         │   │
│  │                                                              │   │
│  │  Penalty = Σ max(r_min - r(θ,φ), 0)²                        │   │
│  │                                                              │   │
│  │  r_min = 0.1 × mean_radius (practical minimum)              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_star = 10000+ (must satisfy)                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### D1: Silhouette Matching (Data Term)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: SH surface projection should match observed silhouettes   │
│                                                                     │
│  Mathematical Form (per camera):                                    │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  Option A: Silhouette IoU                                   │   │
│  │      Loss = 1 - IoU(projected_SH, observed_silhouette)      │   │
│  │                                                              │   │
│  │  Option B: Boundary Distance (recommended)                  │   │
│  │      For reliable boundary points:                          │   │
│  │      Loss = Σ dist(projected_boundary, observed_boundary)²  │   │
│  │                                                              │   │
│  │  Option C: Chamfer Distance                                 │   │
│  │      Bidirectional closest-point distance                   │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weighted by: view_weight[camera] (from overlap/quality analysis)  │
│                                                                     │
│  Total: L_silhouette = Σ_cameras w_cam × Loss(camera)              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### D2: Upper Bound Constraint (for overlapped regions)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: In overlapped regions, we can't see true boundary         │
│           but we know surface can't exceed the visible edge         │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  For overlapped boundary points:                            │   │
│  │      projected_radius ≤ observed_radius                     │   │
│  │                                                              │   │
│  │  ONE-SIDED penalty:                                         │   │
│  │      Penalty = max(projected_radius - observed_radius, 0)²  │   │
│  │                                                              │   │
│  │  No penalty if surface is INSIDE the observed boundary      │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_upper = 10-50                                           │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### P1: Volume Conservation

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Bubble volume is approximately constant                   │
│           (compressibility negligible at lab scales)                │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  V_SH = (1/3) ∫∫ r(θ,φ)³ sin(θ) dθ dφ                      │   │
│  │                                                              │   │
│  │  V_expected = from VH volume or previous frame              │   │
│  │                                                              │   │
│  │  Loss = ((V_SH - V_expected) / V_expected)²                 │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_vol = 10-100                                            │
│                                                                     │
│  Note: Volume from SH can be computed analytically or via          │
│        numerical integration over (θ,φ) grid                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### P2: Curvature Uniformity

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Surface tension makes bubble surfaces smooth              │
│           Mean curvature H should be roughly uniform                │
│                                                                     │
│  Physical Basis: Young-Laplace equation                            │
│      ΔP = 2σH                                                       │
│      Uniform pressure inside → uniform curvature                    │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  H(θ,φ) = mean curvature at each surface point              │   │
│  │                                                              │   │
│  │  Loss = Variance(H) = E[H²] - E[H]²                         │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_curv = 1-10                                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### P3: Maximum Curvature Limit

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Bubbles cannot have arbitrarily sharp features            │
│           Surface tension smooths out high curvature                │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  κ_max = 2 / r_mean  (physical limit based on mean radius)  │   │
│  │                                                              │   │
│  │  Loss = Σ max(|κ(θ,φ)| - κ_max, 0)²                        │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_maxcurv = 5-20                                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### P4: Convexity (Weber Number Dependent)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Small bubbles (low We) should be nearly convex            │
│           Large/fast bubbles (high We) can have concavities         │
│                                                                     │
│  Weber Number: We = ρ v² D / σ                                     │
│      We << 1: surface tension dominates → convex                   │
│      We >> 1: inertia dominates → can deform                       │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  K = Gaussian curvature = κ₁ × κ₂                           │   │
│  │  Convex surface: K > 0 everywhere                           │   │
│  │  Saddle point: K < 0                                        │   │
│  │                                                              │   │
│  │  Loss = Σ max(-K(θ,φ), 0)²                                  │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_convex = 1-10 (scale by 1/We if We known)               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### P5: Aspect Ratio Limit

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Highly elongated bubbles are unstable and break up        │
│           Aspect ratio has physical limit ~3-4                      │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  Compute principal axes via PCA on surface points           │   │
│  │  AR = max_extent / min_extent                               │   │
│  │  AR_max = 3.0 (typical limit)                               │   │
│  │                                                              │   │
│  │  Loss = max(AR - AR_max, 0)²                                │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_ar = 10-50                                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### R1: Spectral Smoothness (ANTI-FLOWER)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Penalize high-frequency SH components                     │
│           This is the PRIMARY defense against "flower pattern"      │
│                                                                     │
│  Why It Works:                                                      │
│      l=0: sphere (mean radius)                                     │
│      l=1: translation (often constrained to 0)                     │
│      l=2: ellipsoid deformation                                    │
│      l≥3: higher-order shape details → often noise/artifacts       │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  Loss = Σ_{l=3}^{l_max} Σ_{m=-l}^{l} (l-2)² × |c_lm|²      │   │
│  │                                                              │   │
│  │  Penalty grows quadratically with degree                    │   │
│  │  l=0,1,2 terms have NO penalty                              │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_spec = 0.5-5                                            │
│                                                                     │
│  Tuning: Increase if seeing flower pattern                         │
│          Decrease if losing real shape details                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### R2: Temporal Smoothness

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Shape shouldn't change drastically between frames         │
│           Leverage temporal continuity for robustness               │
│                                                                     │
│  Mathematical Form:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  First-order (velocity penalty):                            │   │
│  │      Loss = Σ_lm |c_lm(t) - c_lm(t-1)|²                    │   │
│  │                                                              │   │
│  │  Second-order (acceleration penalty, smoother):             │   │
│  │      Loss = Σ_lm |c_lm(t-1) - 2c_lm(t) + c_lm(t+1)|²       │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Weight: λ_temp = 1-10 (higher for noisier data)                   │
│                                                                     │
│  Note: In per-frame fitting, use first-order as prior              │
│        In post-processing, can apply second-order smoothing        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## Total Loss Function

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  L_total = L_hard + L_data + L_physical + L_regularization                  │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │                                                                       │ │
│  │  L_hard = λ_vh × VH_violation                                        │ │
│  │         + λ_star × StarConvexity_violation                           │ │
│  │                                                                       │ │
│  │  L_data = Σ_cameras w_cam × [                                        │ │
│  │               SilhouetteLoss(reliable_points)                         │ │
│  │             + UpperBoundLoss(overlapped_points)                       │ │
│  │           ]                                                           │ │
│  │                                                                       │ │
│  │  L_physical = λ_vol × VolumeLoss                                     │ │
│  │             + λ_curv × CurvatureVarianceLoss                         │ │
│  │             + λ_maxcurv × MaxCurvatureLoss                           │ │
│  │             + λ_convex × ConvexityLoss                               │ │
│  │             + λ_ar × AspectRatioLoss                                 │ │
│  │                                                                       │ │
│  │  L_regularization = λ_spec × SpectralSmoothnessLoss                  │ │
│  │                   + λ_temp × TemporalSmoothnessLoss                  │ │
│  │                                                                       │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Stage 2: Temporal Post-Processing

### Step 2.1: Bilateral Temporal Filtering

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  Purpose: Smooth SH coefficients over time while preserving         │
│           real dynamics (oscillations, deformations)                │
│                                                                     │
│  Method: Bilateral filter                                           │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  For each frame t:                                          │   │
│  │      For each other frame s:                                │   │
│  │          w_time = exp(-(t-s)² / σ_t²)   (temporal distance) │   │
│  │          w_sim = exp(-|c(t)-c(s)|² / σ_c²) (coeff distance) │   │
│  │          w(s) = w_time × w_sim                              │   │
│  │                                                              │   │
│  │      c_smoothed(t) = Σ_s w(s) × c(s) / Σ_s w(s)            │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Parameters:                                                        │
│      σ_t = 2-5 frames (temporal scale)                             │
│      σ_c = 0.1 × mean(|c|) (coefficient similarity scale)          │
│                                                                     │
│  Benefit: Preserves sharp transitions (e.g., bubble oscillation    │
│           mode changes) while smoothing noise                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Step 2.2: Outlier Detection & Repair

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  DETECTION CRITERIA:                                                │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  1. Volume Jump                                             │   │
│  │     |V(t) - median(V)| > 10% → suspicious                   │   │
│  │                                                              │   │
│  │  2. Coefficient Jump                                        │   │
│  │     |c_lm(t) - c_lm(t-1)| > 3σ (local) → suspicious        │   │
│  │                                                              │   │
│  │  3. Reconstruction Confidence                               │   │
│  │     confidence(t) < 0.5 → suspicious                        │   │
│  │                                                              │   │
│  │  4. Reprojection Error Spike                                │   │
│  │     reproj_error(t) > 2 × median(reproj_error) → suspicious │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  REPAIR STRATEGIES:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  Option A: Re-fit with stronger temporal prior              │   │
│  │      Increase λ_temp significantly                          │   │
│  │      Initialize from interpolated neighbor frames           │   │
│  │                                                              │   │
│  │  Option B: Interpolate                                      │   │
│  │      c(t) = lerp(c(t-1), c(t+1), 0.5)                      │   │
│  │      For longer gaps: cubic spline interpolation            │   │
│  │                                                              │   │
│  │  Option C: Flag for manual review                           │   │
│  │      If many consecutive outliers or critical frames        │   │
│  │                                                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Step 2.3: Final Validation

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  VALIDATION CHECKS:                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  □ Volume Conservation                                      │   │
│  │    std(V) / mean(V) < 5%                                    │   │
│  │                                                              │   │
│  │  □ Temporal Smoothness                                      │   │

│  │                                                              │   │
│  │  □ Cross-View Consistency                                   │   │

│  │                                                              │   │
│  │  □ Physical Plausibility                                    │   │
│  │    - AR < 4 for all frames                                  │   │
```

## Key Design Decisions Summary

| Aspect | Decision | Rationale |
|--------|----------|-----------|
| 3D Representation | Spherical Harmonics | Compact, inherently smooth, physics-friendly |
| Max SH Degree | 4-6 (progressive) | Balance detail vs. stability |
| VH Role | Upper bound constraint | More reliable than any single 2D view |
| Overlap Handling | View weighting + upper bounds | Graceful degradation |
| Bad Mask Handling | Cross-validate with VH projection | Robustness |
| Anti-Flower | Progressive fitting + spectral penalty | Key innovation |
| Temporal | Bilateral smoothing | Preserve real dynamics |
| Optimization | L-BFGS-B with bounds | Fast, handles box constraints |
